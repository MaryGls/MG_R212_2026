# Rapport — TP3

## Points clés

### 1. Réussir a garde des élément même en rafraîchissant la page

Grâce à localStorage.setItem, on peut sauvegarder les données dans le navigateur.
Même si on recharge la page, les projets restent enregistrés en mémoire.

### 2. Cree un filtrage interactif
 
Grâce à dataset.tag, on peut récupérer les données du HTML pour savoir quel filtre est sélectionné, puis on utilise .filter() pour afficher uniquement les projets correspondants, ce qui permet de créer un filtrage interactif. 

## Utilisation de l'IA

Aucune IA utilisée lors de cette séance.
